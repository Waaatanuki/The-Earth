## 奥义记录

### 奥义 1：刃鏡螺旋

对敌方单体造成4.5倍土属性伤害

自身获得绝对魔灭(消去不可)，持续2回合(包括奥义回合)

绝对魔灭效果

- 回合结束时，追加发动1次SK

## 主动技能

### 技能 1：不可侵海域 CD 7回合

自身获得以下效果

- 自身净化全部弱体状态
- 不可侵海域，持续3回合

不可侵海域(消去不可/无法延长)效果

- 自身防御力 +300%
- 自身弱体耐性 +100%
- 自身水变换
- 受到的单次水伤害，最大值锁定为1500
- 自身援护（全体）
- 回合结束时，消耗1层刃镜
- 没有刃镜时，效果提前结束

### 技能 2：ヒルデブランド CD 7回合

对敌方全体造成4倍土属性伤害(上限约63万)

我方全体获得刃镜结界(永续/消去不可)

自身展开1层刃镜(最大5层/消去不可)

刃镜结界效果

- 防御力UP（累积）(每次9%/最大45%)

### 技能 3：ニーベルン・ザント CD 6回合

对敌方全体施加以下弱体，持续180秒，基本成功率100%

- 水属性攻击力- -20%
- 重力

消耗1层刃镜：追加命中率-（独占） -50%，持续2回合，基本成功率100%

- 自身防御力UP(每层10%/最大50%)
- 3层后追加 自身再生(最大HP的10%/上限1000)
