## 奥义记录

### 奥义 1：三千一穿明王破斬・轟

对敌方单体造成4.5倍土属性伤害

自身技能即刻可用

## 主动技能

### 技能 1：波濤連斬 CD 6回合

对敌方单体进行3次攻击，每次造成2倍土属性伤害(单次上限约18万/合计约55万)

并施加以下弱体，持续3回合

- 防御力-（独占） -25%
- 承受伤害上升（独占）(上限3万)

处于海斩新明王时：自身额外获得自身乱击(3段)，持续1回合

### 技能 2：瞬門・止水 CD 6回合

自身获得以下强化

- 自身敌对心特殊UP，持续1回合
- 自身分身（次）(1次)，持续到消耗完

处于海斩新明王时：自身额外获得自身再攻击，持续1回合

### 技能 3：波門・怒濤 CD 6回合

自身获得以下强化

- 自身暴击率UP(100%发动/20%额外伤害)，持续4回合
- 自身伤害上限 +20%，持续4回合
- 自身土属性奥义追击(50%/1次)，持续到消耗完

处于海斩新明王时：自身额外获得自身会心，持续4回合

## 被动技能记录

### 被动 1：新境を往く神狼

拥有独有效果新境的神狼(最大6层/消去不可)

- 战斗开始时，获得3层
- 受到伤害的回合，失去2层
- 回合结束时，获得1层

自身回避时效果

- 对敌方单体进行6次攻击，每次造成1倍土属性伤害(单次上限约8万/合计约48万)
- 获得1层新境的神狼(最大6层/消去不可)

新境的神狼效果

- 自身攻击力UP（婚戒）(每层10%/最大60%)
- 自身伤害上限UP(每层5%/最大30%)
- 回合结束时，自身奥义值充能(每层5%/最大30%)

### 被动 2：心に吹く潮風

自身初始奥义值 +100%

自身普通攻击无法获得奥义值 / 自身必定DA / 自身回避率（独立） +30%

### 被动 3：忘れられない夏の宵

回合结束时：若自身在本回合内发动过奥义，获得海斩新明王，持续3回合

海斩新明王(消去不可/无法延长)效果

- 自身土属性追击(SP类)(30%)
- 自身普通攻击伤害 +20%
- 自身必定TA
- 自身奥义封印
