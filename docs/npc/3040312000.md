## 主动技能

### 技能 1：ロウ・プリズン CD 8回合

对敌方全体造成5倍土属性伤害(上限约63万)

并施加以下弱体

- 元素不和，持续5回合，基本成功率200%
- 审判之槛，持续2回合，基本成功率90%

元素不和（消去不可）效果

- 造成的伤害全部转为水(不包括无属性伤害)
- 承受伤害时被判定为水目标(不影响跨属弱体耐性与跨属CUT)

◆审判之槛效果：高级恐怖（独占）

### 技能 2：エクリプティカ CD 5回合

对敌方单体造成6倍土属性伤害(上限约63万)

并随机施加以下弱体之一，持续180秒，基本成功率100%

- 火属性攻击力- -30%
- 水属性攻击力- -30%
- 土属性攻击力- -30%
- 风属性攻击力- -30%

自身获得一种对应强化(永续/消去不可)

- 自身火属性攻击力 +30%
- 自身水属性攻击力 +30%
- 自身土属性攻击力 +30%
- 自身风属性攻击力 +30%

### 技能 3：ザ・ヴァイス CD 8回合

驱散自身以外的敌我全体全部强化状态

自身获得以下效果

- 自身奥义即刻发动
- 自身奥义伤害2 +150%(消去不可)，持续1回合
- 自身奥义伤害上限 +90%(消去不可)，持续1回合
