## 主动技能

### 技能 1：シュピンネンネッツ CD 10回合

我方土属性角色获得以下强化

- 水属性伤害减轻(50%)，持续2回合
- 弱体无效(1次)，持续到消耗完
- 驱散防御(1次)，持续到消耗完

### 技能 2：ビーネンシュティッヒ CD 6回合

对敌方单体进行5次攻击，每次造成1倍土属性伤害(单次上限约10万/合计约54万)

并施加以下弱体，持续180秒，基本成功率100%

- 攻击力DOWN（累积）(每次10%/最大40%)
- 防御力DOWN（累积）(每次10%/最大40%)
- 水属性攻击力- -20%

---

自身处于密侦的秘策时：没有受到伤害的回合，自动发动1次本技能

### 技能 3：トート・ミミクリー CD 初次 2回合

再使用不可

对敌方单体造成10倍土属性伤害(上限约130万)

伪造自己的死亡，与第一名土属性后备队员交换位置

替换上场的角色获得密侦的记录(消去不可)，持续至麦考伊再次登场

麦考伊再次登场时，我方土属性角色获得密侦的秘策(永续/消去不可)

◆后排只有土属性角色时，才可使用

密侦的记录和密侦的秘策效果

- 弱体成功率 +30%
- 暴击率UP(100%发动/20%额外伤害)
- 回避率 +20%
- 会心
