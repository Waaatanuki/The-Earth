## 主动技能

### 技能 1：ハボック・ピラー CD 7回合

对敌方全体进行4次攻击，每次造成2倍土属性伤害(单次上限约17万/合计约68万)

并施加土属性防御力DOWN（累积）(每次10%/最大40%)，持续180秒，基本成功率100%

自身自身奥义值 +20%

### 技能 2：ウッズ・オブ・ライト CD 12回合

我方土属性角色获得以下强化，持续4回合

- 土属性攻击力 +50%
- 弱点属性追击
- 活性(上限1000)

### 技能 3：アッシュ・インサイト CD 7回合

自身获得森鸟的守护者，持续1回合

森鸟的守护者(消去不可)效果

- 自身TA +100%
- 自身暴击率UP(100%发动/100%额外伤害)
- 自身再攻击
- 普通攻击后，自动发动1次sk

## 被动技能记录

### 被动 1：ベンヌクロース

自身初始拥有自身不死身(1次/消去不可)

自身常驻以下效果

- 自身普通攻击无法获得奥义值
- 自身普通攻击伤害 +20%
- 自身驱散免疫
- 发动TA时，sk使用间隔缩短(1回合)

### 被动 2：森と鳥と共に

自身攻击行动结束时：若本回合进行了至少2次攻击行动，对敌方全体施加破爆之龟裂，持续3回合

破爆之龟裂(消去不可/无法延长)效果

- 承受伤害增幅（独占） +20%
- 累计受到40次土属性暴击伤害后，回合结束时消耗破爆之龟裂产生以下效果
- 该敌人受到300万无属性伤害

并被施加承受伤害增幅（独占） +30%(消去不可/无法延长)，持续1回合
