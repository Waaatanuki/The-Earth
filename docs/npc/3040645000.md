## 奥义记录

### 奥义 1：破邪閃・月影

对敌方单体造成4.5倍土属性伤害

并施加以下效果

- 恐怖（独占），持续3回合包括奥义回合
- 减速

自身获得自身承受伤害减少(3000)，持续仅奥义回合

## 主动技能

### 技能 1：シェードエッジ CD 6回合

对敌方单体进行2次攻击，每次造成4倍土属性伤害(单次上限约48万/合计约97万)

并施加以下弱体，持续180秒，基本成功率100%

- 土属性防御力DOWN（累积）(每次10%/最大40%)
- 特殊技伤害DOWN（累积）(每次6%/最大30%)

然后驱散1个强化状态

### 技能 2：カエルラドレイン CD 5回合

对敌方全体造成6倍土属性伤害(上限约82万)

我方土属性角色获得以下效果

- HP回复(造成伤害的10%/上限1500)
- 弱体效果短缩(2回合)

对处于濒死的角色：性能提升至HP回复(造成伤害的20%/上限3000)

### 技能 3：黒鳳の護剣 CD 10回合

自身获得黑凤之护剑，持续5回合

黑凤之护剑(消去不可)效果

- 自身攻击力（婚戒） +50%
- 自身必定TA
- 自身土属性追击
- 自身伤害上升(上限5万)
- 受到的单次属性伤害，最大值锁定为5000
- 普通攻击后，自动发动1次sk

## 被动技能记录

### 被动 1：迷いなき信念

自身成功驱散敌方强化状态时，获得以下效果

- sk使用间隔缩短(1回合)
- 攻击力UP（累积/独立）(每次10%/最大50%/永续)
- 防御力UP（累积）(每次10%/最大50%/永续)
- 乱击(3段/1次)，持续到消耗完

### 被动 2：黒の継承者
