## 主动技能

### 技能 1：悪運散虎 CD 连接 3回合

对敌方单体造成4.5倍土属性伤害(上限约63万)

并施加以下弱体，持续180秒，基本成功率100%

- 攻击力down（累积）(每次10%/最大40%)
- 防御力down（累积）(每次10%/最大40%)

然后驱散1个强化状态

◆根据目标虎带层数，随机追加以下效果(每层1个)

- 水属性攻击力- -20%，持续180秒，基本成功率100%
- 土属性防御力- -20%，持续180秒，基本成功率100%
- 弱体耐性- -20%，持续180秒，基本成功率100%
- 魅惑，持续180秒，基本成功率100%
- 黑暗（独占），持续3回合，基本成功率100%

55级后 性能强化

### 技能 2：良運招虎 CD 连接 3回合

对敌方单体造成4.5倍土属性伤害(上限约63万)

自身获得以下强化(永续)

- 自身攻击力up（累积）(每次10%/最大40%)
- 自身防御力up（累积）(每次10%/最大40%)
- 自身伤害上限UP（累积）2(每次2%/最大10%)

◆根据目标虎带层数，自身随机追加以下效果(每层1个)

- 自身驱散防御(1次)，持续到消耗完
- 自身幻影(1次)，持续到消耗完
- 自身屏障，持续到消耗完
- 自身奥义再发动，持续到消耗完
- 自身奥义值 +30%

75级后 性能强化

### 技能 3：双虎風水 CD 12回合

自身获得以下强化，持续1回合

- 自身分身
- 自身全体援护
- 双虎风水(消去不可)

双虎风水效果

- 自身无法进行攻击
- 下回合获得以下强化，持续1回合
  - 自身攻击大幅UP
  - 自身必定TA

### 技能 4：戯遊絡虎 CD /

习得：100级

再使用不可

自身获得戏游络虎(消去不可)

◆同时拥有3层金虎和银虎时，才可使用

戏游络虎效果

- 自身普通攻击伤害 +20%
- 自身技能攻击伤害 +20%
