## 主动技能

### 技能 1：祝福の接吻 CD 10回合

自身以外的我方指定土属性角色获得巌迫的祝福(永续/消去不可)

若目标已具有巌迫的祝福，则获得以下效果

- 净化全部弱体状态
- HP回复(最大HP的100%/上限1万)

巌迫的祝福效果

- 土属性攻击力 +50%
- 防御力 +100%
- 必定DA
- 弱体耐性 +100%
- 土属性追击

### 技能 2：降砂岩 CD 8回合

对敌方随机目标进行6多段伤害技能，每次造成当前HP 10%的无属性伤害(单次上限66.6666万/合计399.9996万)

并对敌方全体施加以下效果

- 驱散1个强化状态
- 减速，基本成功率100%

### 技能 3：『金』の楔石 CD /

再使用不可

自身获得『金』之楔石(永续/消去不可)

『金』之楔石效果

- 自身攻击力（婚戒） +100%
- 自身防御力 +300%
- 自身伤害上限 +100%
- 自身必定TA
- 自身弱体免疫
- 每4回合，自动发动1次sk
- 进行攻击后，下回合无法攻击
