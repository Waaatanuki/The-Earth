- 水之基座(1次/消去不可)
- 风之基座(1次/消去不可)

- 弱体耐性 +200%
- 驱散免疫
- 再生(上限1000)
- 第2次追加 格挡(100%发动/减少20%伤害)
- 第2次追加 承受伤害减少(3000)

### 技能 3：ピィ・ケ・アイナ CD 0回合

对敌方全体进行12次攻击，每次造成2.5→10倍土属性伤害(性能逐段变化(对敌方全体进行2次多段伤害技能，每次造成4倍土属性伤害

(单次上限约44万/合计约88万)

对敌方全体进行6次多段伤害技能，每次造成2.5倍土属性伤害

(单次上限约10万/合计约60万)

对敌方全体进行3次多段伤害技能，每次造成5倍土属性伤害

(单次上限约64万/合计约192万)

对敌方全体造成10倍土属性伤害(上限约120万))/合计上限约460万)

并施加以下效果

- 大地石槛(消去不可/无法延长)，持续1回合
- CT清空，基本必中
- 驱散3个强化状态

自身获得以下效果

- 女王檄令(消去不可)，持续3回合
- 其他技能自身立即可用

◆有敌人处于6层土之基座时，才可使用

◆消耗全部土之基座

- 乱击(2段)
