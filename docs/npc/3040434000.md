对敌方全体进行6多段伤害技能，每次造成1倍土属性伤害(单次上限约30万/合计约180万)

- 冰牢（独占），持续1~2回合，基本成功率90%
- 水属性攻击力- -20%，持续180秒，基本成功率200%

◆极寒囚笼：sk的效果量提升至对水属性伤害 +30%

### 技能 2：テュロス・グラキエース CD 10回合

我方全体获得弱体无效，持续到消耗完

自身获得推罗寒冰，持续5回合

◆推罗寒冰：sk的效果量提升至奥义值 +20%

### 技能 3：エパミノンダス CD 7回合

对敌方单体造成8倍土属性伤害(上限约80万)

并施加1层冰结（叠层）(最大10层/消去不可)，持续180秒，基本必中

对处于至少5层冰结（叠层）的敌人：自身获得埃帕米农达斯，持续3回合

◆埃帕米农达斯：sk效果全体化
