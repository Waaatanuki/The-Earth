## 奥义记录

### 奥义 1：手合わせ錬成

对敌方单体造成4.5倍土属性伤害

自身技能使用间隔缩短(1回合)

## 主动技能

### 技能 1：岩の拳 CD 7回合

对敌方单体造成9倍土属性伤害(上限约102万)

并驱散1个强化状态

### 技能 2：石壁錬成 CD 10回合

我方土属性角色获得以下强化

- 水属性CUT(60%)，持续1回合
- 弱体无效(1次)，持续到消耗完
- 驱散防御(1次)，持续到消耗完

### 技能 3：土柱の拘束 CD 6回合

对敌方全体造成3倍土属性伤害(上限约63万)

并施加以下弱体，持续2回合

- 攻击力-（独占） -30%
- DA-（独占） -100%
- TA-（独占） -100%
- 特殊技伤害-（独占） -20%

## 被动技能记录

### 被动 1：鋼の錬金術師

拥有独有效果钢之意志(最大5层/永续/消去不可)

- 自身发动技能时，获得1层

普通攻击后：根据钢之意志层数对敌方单体进行最多5次技能追击，每次造成1倍土属性伤害(单次上限约13万/合计最多约67万)

钢之意志效果

- 自身攻击力UP(每层6%/最大30%)
- 自身DA UP(每层20%/最大100%)
- 自身TA UP(每层20%/最大100%)
- 自身技能伤害UP(每层0.1倍/最大0.5倍)
- 自身技能伤害上限UP(每层6%/最大30%)

### 被动 2：錬成陣

回合结束时：若敌方单体拥有可消去的强化状态，自动发动1次技能1

回合结束时：若有敌人CT处于最大，自动发动1次技能3
