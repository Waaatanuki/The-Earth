## 被动技能记录

### 被动 1：鳥神宮の主

仅在前排有效

我方全体获得独有效果鼓音(最大10层/消去不可)

- 普通攻击时，根据连击数获得1/2/3层
- 反击时，获得1层
- 发动奥义时，获得1层
- 使用攻击技能时，获得1层

◆鼓音显示上只有4阶段，实际对应关系如下

图标 / 鼓音 / 鼓音 / 鼓音 / 鼓音

对应层数 / 1~3 / 4~6 / 7~9 / 10

◆鼓音的持续时间为3回合（包括触发回合），因此因麻痹或睡眠等效果2回合无法行动时会清零

### 被动 2：飛ぶが如く

习得：95级

仅在前排有效

我方全体根据各自的鼓音层数获得伤害UP(上限每层2000/最大20000)

10层鼓音额外提供弱体无效(1次)效果，触发后清空鼓音层数

◆与其它弱体无效共同存在时，触发后一并消耗
